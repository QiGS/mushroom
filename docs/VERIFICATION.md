# 验证记录

验证日期：2026 年 10 月 31 日。环境为 Windows、Node.js 22.20.0、Microsoft Edge、Three.js 0.187.0、Vite 7.3.1。

## 已执行

- `npm test`：56 项测试通过（此前 46 项，加本轮昼夜、水中移动、烹饪、交易、补给与素材 10 项）。
- `npm run build`：生产构建通过。Three.js 独立包约 590 KB，gzip 约 147 KB；主应用包约 234 KB。构建仍有 Three.js 分包超过 500 KB 的体积提示。
- 生产预览页面与 `assets/traveler.glb` 返回 HTTP 200。
- 检查生产构建不包含开发验收面板的文字与入口。
- 浏览器检查生产首页、主角与场景渲染、开始游戏，控制台没有捕获到错误或警告。
- 开发场景经真实 UI 操作验证采集计数、首次图鉴发现、揭开菌窝、宝箱奖励、第二关守卫受击与血条变化、第三关回声解谜、地标记录和石门面板。
- 390 × 844 视口检查 HUD 与图鉴布局，修正交互提示与小地图的重叠，并恢复浏览器原始尺寸。
- `docs/preview.jpg` 来自生产构建的浏览器截图。
- 跨平台启动服务通过本机 HTTP 冒烟检查：首页、模型 MIME 与长度、404、405 和目录穿越拦截。Mac `.command` 通过 Bash 语法检查。
- macOS 便携包包含官方 Node.js 22.23.4 的 arm64 / x64 二进制，下载时校验官方 SHA256；ZIP 为启动器和两种运行文件保存 POSIX 执行权限。GitHub Actions 增加两种 Mac 架构的源码和解压便携包启动检查，结果以对应提交的 Actions 记录为准。

## 自动化覆盖

测试覆盖三关 × 三种天气下的食材供给与可通关条件；容量限制与收藏品豁免；采集和结算去重；隐藏菌窝、守卫、石门的前置条件；出售保留任务食材；错误谜题不清进度；晚归奖励；重复游玩的首次奖励保护；存档往返和损坏存档；跨章节永久奖励与本局状态；消耗品规则；天气线索与生成一致性；场景有限几何、月牙菌所在岸边位置与资源释放。

## 验证范围

浏览器交互抽查结合开发模式的定位按钮完成，未把三关各自十余分钟的完整游玩过程全部人工跑一遍。自动化可通关检查验证规则与食材供应，不替代完整的人类游玩体验。移动端验证为桌面浏览器窄屏检查，未在实体手机上测试帧率与多点触控；不宣称所有设备达到固定帧率。

macOS 的自动化启动检查不覆盖 Finder 双击、系统安全提示或 Safari 中的人工游玩体验；这些项目尚未在实体 Mac 上手动验证。

主角源素材没有骨骼；Windows 与 macOS 现使用运行时绑定的程序化骨架，其他平台保留原动画。三关共享基础地形，使用不同布景和互动规则。部分分镜演出和独立服装定制界面不在本版本的已完成范围内，详见 README。

## 桌面动作与视角更新

- Windows 与 macOS 均启用 16 关节骨架、加减速、走跑步态混合、手臂与装备随动、跳跃落地、转身倾斜及鼠标捕获。Mac 平台检测覆盖 Safari 的 Macintosh 标识，并排除使用桌面标识的 iPad。
- 实际 GLB 全部 45,663 个顶点通过权重归一化和绑定姿态一致性检查；动作测试检查交替抬脚、落地高度、停止过渡，以及跳跃、闪避、采集、挥杖时的有限坐标与变形范围。
- 输入状态测试覆盖不按住鼠标的相对位移、双轴灵敏度、俯仰边界、重复捕获、释放后暂停、菜单保持以及失败后重试。该检查使用模拟 Pointer Lock 事件，不替代浏览器真实输入测试。
- Edge 开发页中确认原主角外观和 16 关节模型正常渲染，前后近景没有捕获到控制台错误。后台标签页的自动捕获被浏览器拒绝，拖动后备提示正常出现。
- 随后 Windows 原生浏览器自动操作因工具无法可靠识别当前窗口网址而中止。本轮未完成真实鼠标锁定后的连续旋转、Esc 退出和完整动态步态的人工手感验收。

## macOS 同步更新

- 鼠标测试补充事件回调式（不返回 Promise）的 Pointer Lock，以及完全缺失该接口时的拖动后备操作。
- macOS 便携包重新构建，保留 Apple 芯片和 Intel 两套官方运行环境与 POSIX 执行权限；已能启动的旧包只需替换 `dist`。
- Apple 芯片和 Intel Mac 的源码及解压包启动检查由 GitHub Actions 运行，结果以本次提交对应的记录为准。未在实体 Mac 浏览器中人工验证鼠标手感或 Gatekeeper 提示。
