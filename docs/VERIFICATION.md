# 验证记录

验证日期：2026 年 10 月 31 日。环境为 Windows、Node.js 22.20.0、Microsoft Edge、Three.js 0.187.0、Vite 7.3.1。

## 已执行

- `npm test`：14 项测试通过。
- `npm run build`：生产构建通过。Three.js 独立包约 590 KB，gzip 约 147 KB；主应用包约 138 KB，gzip 约 50 KB。
- 生产预览页面与 `assets/traveler.glb` 返回 HTTP 200。
- 检查生产构建不包含开发验收面板的文字与入口。
- 浏览器检查生产首页、主角与场景渲染、开始游戏，控制台没有捕获到错误或警告。
- 开发场景经真实 UI 操作验证采集计数、首次图鉴发现、揭开菌窝、宝箱奖励、第二关守卫受击与血条变化、第三关回声解谜、地标记录和石门面板。
- 390 × 844 视口检查 HUD 与图鉴布局，修正交互提示与小地图的重叠，并恢复浏览器原始尺寸。
- `docs/preview.jpg` 来自生产构建的浏览器截图。

## 自动化覆盖

测试覆盖三关 × 三种天气下的食材供给与可通关条件；容量限制与收藏品豁免；采集和结算去重；隐藏菌窝、守卫、石门的前置条件；出售保留任务食材；错误谜题不清进度；晚归奖励；重复游玩的首次奖励保护；存档往返和损坏存档；跨章节永久奖励与本局状态；消耗品规则；天气线索与生成一致性；场景有限几何、月牙菌所在岸边位置与资源释放。

## 验证范围

浏览器交互抽查结合开发模式的定位按钮完成，未把三关各自十余分钟的完整游玩过程全部人工跑一遍。自动化可通关检查验证规则与食材供应，不替代完整的人类游玩体验。移动端验证为桌面浏览器窄屏检查，未在实体手机上测试帧率与多点触控；不宣称所有设备达到固定帧率。

主角源素材没有骨骼，当前使用程序化步态与弯腰；三关共享基础地形，使用不同布景和互动规则。部分分镜演出和独立服装定制界面不在本版本的已完成范围内，详见 README。
